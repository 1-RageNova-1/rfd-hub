# UI assets

Put the Roblox-style game icon collage here as:

**`collage.jpg`**

(or `collage.png` — if png, change the url in `styles.css` from `collage.jpg` to `collage.png`)

Path used by CSS:

```text
client/ui/assets/collage.jpg
```

Used as the fixed background for the whole app (login, home, avatar).
